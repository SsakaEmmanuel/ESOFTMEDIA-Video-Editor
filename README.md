# ESOFTMEDIA VIDEO EDITOR

**Create. Edit. Anywhere.** 🎬

A premium Android video editor designed to run fully offline. Your media and projects stay on your device.

## Identity
- App: ESOFTMEDIA VIDEO EDITOR
- Brand: ESOFTMEDIA
- Visual: Cyan + purple play/E mark, dark cinematic interface
- Platform: Android
- Offline-first: no account, no cloud, no Internet permission

## Current foundation
- Kotlin + Jetpack Compose
- Cinematic dark editor home
- Android system video picker
- Local-only design
- GitHub Actions debug APK build

## Build
Push to `main` or open **Actions → Android APK Build → Run workflow**. The workflow builds a debug APK and uploads it as an artifact.
